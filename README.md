# Tattoo English

Статический сайт для обучения английскому тату- и пирсинг-мастеров: маршрут с целями, модули, словарь с озвучкой, тренажёр и экспорт в Quizlet. Без сервера и логинов — прогресс в `localStorage`, отдельно для каждого ученика.

## Страницы
| Файл | Что там |
|---|---|
| `index.html` | выбор ученика, общий прогресс |
| `route.html` | маршрут: грамматика, навыки, чек-лист целей, прогресс-бар |
| `modules.html` | модули курса + блоки фраз / правил чтения с 🔊 |
| `dict.html` | словарь: поиск, фильтры (категория, модуль, набор, выучено), экспорт в Quizlet (TAB или ` - `, EN→RU / RU→EN, IPA / русская транскрипция, пример) |
| `train.html` | карточки, выбор перевода, «послушай и выбери» (en-GB), правописание; невыученные идут первыми |
| `errors.html` | реестр ошибок ❌/✅ + упражнение «исправь ошибку» |
| `howto.html` | формат урока, инструменты (Meet / Docs / Quizlet) |

## Данные
```
data/vocab.json              единый словарь (генерируется, руками не править)
data/courses/<курс>.json     маршрут, модули, категории словаря курса
data/students/index.json     список учеников
data/students/<id>.json      профиль: уровень, курс, расписание, формат урока, ошибки
data/source/                 исходники словаря
data/quizlet/*.txt           выгрузка по категориям (генерируется)
tools/build_vocab.py         сборка словаря
```

### Добавить ученика
1. Скопируй `data/students/tattoo-a2.json` в `data/students/<новый-id>.json`, поменяй поля.
   `course` — `tattoo` или `piercing`. Можно переопределить `route`, `modules`, `categories` прямо в файле ученика.
2. Допиши `<новый-id>` в `data/students/index.json`.

### Добавить слова
- Наборы Quizlet — в `data/source/my_vocab.txt` (формат `русский - English (транскрипция)`); для новых слов добавь категорию/модуль/пример в `data/source/extras.json`.
- Пирсинг — в `data/source/piercing.json`.
- Затем: `python3 tools/build_vocab.py` — склеит дубли по английскому слову, подставит IPA (британский словарь [Britfone](https://github.com/JoseLlarena/Britfone), MIT) и транскрипцию русскими буквами, пересоберёт `data/vocab.json` и `data/quizlet/`.

## Локальный запуск
Данные грузятся через `fetch`, поэтому нужен сервер (двойной клик по файлу не сработает):
```
python3 -m http.server 8000   # → http://localhost:8000
```

## Деплой
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Свой домен — файл `CNAME` с доменом + DNS-запись.
- **Netlify:** подключить репозиторий, build command пустой, publish directory `.`.

Прогресс привязан к домену: при переезде на новый домен он начнётся заново.
